# Fork-surface ledger (pointer)

The canonical ledger is [docs/contrib/fork-surface.md](../../../docs/contrib/fork-surface.md): every
fork-owned path or pattern with the boss-mobile role that resolves merge conflicts in it. It lives in
`docs/contrib/` so it ships with the repository independently of the agent-team files (PD-9). The merge
rules are in [docs/contrib/upstream-merges.md](../../../docs/contrib/upstream-merges.md).
