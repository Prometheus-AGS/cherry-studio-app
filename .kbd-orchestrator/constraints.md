# KBD Constraints — Cherry Studio Mobile

Generated by `/kbd-init` on 2026-09-26. Sources: `AGENTS.md` / `CLAUDE.md` (no "Never Do"
section, so rules are derived from its directives), `docs/guides/testing-and-ci.md`, and
`.github/workflows/pr-ci.yml`.

Command policy: pnpm@12.2.1; no mandatory env prefix or external storage path. Workspace packages
must be built (`pnpm packages:build`) before typecheck/test — the root scripts already do this.

Path-ownership exceptions (do not treat as disposable tool state):
- `.agents/skills/` and `.claude/skills/` hold tracked, upstream-owned project skills managed by
  `pnpm skills:sync`. Keep upstream skill files unchanged; their `.gitignore` files are generated.
- `.maestro/`, `.rnstorybook/`, `.github/`, `.vscode/` are tracked project config.
- `openspec/` is the spec source of truth for KBD/OpenSpec.

```yaml
constraints:

    severity: blocking
    description: 'Full repository type check passes (builds workspace packages first)'
    command: 'pnpm typecheck'

  - id: lint-passes
    severity: blocking
    description: 'oxlint + expo lint pass'
    command: 'pnpm lint'

    command: 'pnpm format:check'

  - id: i18n-complete
    severity: blocking
    description: 'New or changed user-visible copy is translated directly into every supported locale in the same change'
    command: 'pnpm i18n:check'

  - id: no-auto-translation
    severity: blocking

    note: 'Manual review of new workflows, scripts, and dependencies'

  - id: upstream-skills-unchanged

    command: 'pnpm skills:check'

  - id: ui-platform-boundaries

    command: 'pnpm ui:check-boundaries'

  - id: docs-links-valid
    severity: blocking
    description: 'Documentation links resolve'
    command: 'pnpm docs:check-links'

  - id: no-console-log
    severity: blocking
    description: 'No console.log in committed app source'
    check: "grep -rn 'console\\.log' src/ --include='*.ts' --include='*.tsx'"

  - id: no-hardcoded-secrets
    severity: blocking
    description: 'No hardcoded API keys, tokens, or passwords (use .env / EAS secrets)'
    check: "grep -rnE 'sk-[A-Za-z0-9]{20,}|(api_key|API_KEY|secret)\\s*[:=]\\s*[\"\\x27][A-Za-z0-9]{12,}' src/ packages/"

  - id: design-tokens-consistent
    severity: blocking
    description: 'Design tokens, app theme, and icons pass checks when design/UI tokens change'
    command: 'pnpm design:check'
    applies_when: 'packages/design-tokens/** or packages/ui/** icons change'
```

## Workflow Triggers

```yaml
workflow_triggers:
  - event: on_iteration_complete
    action:
      type: command
      target: 'pnpm typecheck'

  - event: on_change_complete
    action:
      type: command
      target: 'pnpm lint && pnpm format:check && pnpm test:app -- --onlyChanged --runInBand'
```

Commits are not automated by a trigger: follow `docs/guides/git-workflow.md` and commit only when
asked.
